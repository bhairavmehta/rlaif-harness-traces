The learner — how the policy over harness levers moves, iteration by iteration

Factored Bernoulli policy πθ(a)=Πσ(θi) over the five levers, starting at the 50/50 reference policy. Reward = judge weighted score on a pinned minibatch − hard-gate rate. GRPO uses the group mean as its baseline; DPO updates on best-vs-worst pairs; UCB1 is the structure-free comparator.

Nightly cycle — baseline replay → single-lever ablations → full replay → artifacts

Credit assignment is measured: each lever is applied alone on the same pinned episodes and its judge delta is its credit. Recommendations carry measured lift, policy-level lift, and production evidence from the redacted traces; failures seen in production but not exercised by replay are flagged as coverage gaps instead of approvals.

Production traces — compliance verdicts from the writeback table, normalized and root-caused

The export is fragmented JSON with OCR-mangled policy ids. Ingest is tolerant and every repair is counted. FAIL verdicts are bucketed by a root-cause classifier and mapped to the harness lever that owns the fix; judge-health checks surface verdicts whose own reasoning contradicts the label.

Governed policy catalog & the action-completion judge prompt

General (GEN) policies apply to every journey; journey policies add on top. CRITICAL policies are hard gates — a violating variant is rejected before scoring. The action-completion prompt decides one boolean on the final state, judging containment on quality, never frequency.

What each lever changes — the entire optimization surface, as data

Each patch is a named, reversible config change to agent descriptions, tool metadata, preconditions/phases, output contracts, or the instruction layer. Behavior changes through exactly one path: this metadata.
